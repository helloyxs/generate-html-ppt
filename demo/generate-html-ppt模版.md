# 用一句话生成 HTML PPT

把下面整段提示词复制给 AI，然后只需把「你的需求」换成自己的想法、材料或大纲即可。你不需要先设计每一页，也不需要会写代码。

```md
请调用 `generate-html-ppt` 技能，帮我制作一份 HTML 演示文稿。

## 我的需求
[在这里用自然语言说出你的想法；也可以直接粘贴文章、会议纪要、大纲、数据或 PPTX 文件路径。]

## 可选补充（不知道可留空）
- 受众/使用场景：[例如：给管理层汇报、客户提案、培训分享、公开演讲]
- 期望页数：[例如：8 页；不填则请按内容自动规划]
- 风格或情绪：[例如：专业克制、科技感、轻松、有品牌色；不填则请推荐]
- 品牌素材：[例如：Logo、品牌色、截图、照片、文件路径；没有则留空]
- 必须包含/不能出现的内容：[可留空]

## 工作方式
1. 先判断我的需求属于：从零制作 PPT、PPTX 转 HTML，还是为内容制作封面；如果信息已足够，不要重复询问我已经提供的内容。
2. 从我的口述或材料中提炼：目标、受众、核心信息、叙事结构、建议页数、视觉方向和素材需求。
3. 未指定的信息请采用合理默认值，并用不超过 6 条的“本次假设”简短说明；只有主题、现有材料或关键受众完全缺失且会明显影响结果时，才一次性集中追问。
4. 默认先输出一份精简的 PPT 简报：推荐风格、页数、逐页标题与每页的表达目的。随后按技能的正常确认流程继续，降低返工。

## 快捷指令（任选其一，放在需求最后）
- `先给我提纲和风格建议`：只给 PPT 简报和 2–3 个风格建议，等待我选择后再制作。
- `直接生成最终版`：我已确认内容方向；跳过风格预览和灰度骨架确认，直接制作完整成品，并在交付前完成视觉与交互检查。

## 成品质量与交付
- 根据主题与场景选择合适的设计系统，不要被固定的页数、深浅主题或版式限制。
- 采用固定 16:9 舞台；正文保持大字号、清晰层级与统一视觉基调，避免逐页深浅色无故跳变。
- 保留完整的上一页、下一页、进度、全览和全屏交互，以及键盘导航；检查全览跳转、全屏和缩放是否可用。
- 优先使用我提供的 Logo、截图、照片和数据。需要配图时，如可用绘图工具则生成匹配插图；如不可用，则改用信息图、图表或结构化图形，绝不编造图片链接或保留无意义占位。
- 创建一个可直接打开的单文件 HTML 演示文稿，完成视觉检查后打开它，并返回文件链接与一段简短的交付说明；不要在聊天中默认粘贴整份 HTML 源码。
```

## 使用小提示

- 只有一个主题也可以，例如：“我想做一份关于 AI 如何帮行政团队节省时间的培训 PPT，面向刚开始使用 AI 的同事。”
- 有现成材料时，直接粘贴即可；AI 会先整理，再避免重复提问。
- 想最快拿到可看版本，在需求末尾加上 `直接生成最终版`。
- 想先减少返工，在需求末尾加上 `先给我提纲和风格建议`。

更多可直接复制的写法见 [generate-html-ppt模版示例.md](./generate-html-ppt模版示例.md)。

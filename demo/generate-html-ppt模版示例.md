# `generate-html-ppt` 模板使用示例

下面三种写法都可以直接复制给 AI。方括号里的内容替换成你的实际信息即可。

## 1. 只有模糊想法

```md
请调用 `generate-html-ppt` 技能，帮我制作一份 HTML 演示文稿。

我想做一份给公司新同事的培训 PPT，主题是“用 AI 把重复的行政工作交给机器”。希望大家听完能马上知道哪些工作能做、怎么开始做，也要提醒大家最终审核责任仍在人。

受众/使用场景：新入职的职能岗同事，45 分钟培训
风格或情绪：友好、现代、不要太技术化
先给我提纲和风格建议
```

预期的第一步：AI 会把这句话整理成受众、目标、建议页数和逐页提纲，并给出适合培训场景的风格建议；不会要求你先填每页标题。

## 2. 已有大纲，直接生成

```md
请调用 `generate-html-ppt` 技能，帮我制作一份 HTML 演示文稿。

请把以下内容制作成一份管理层周报：
1. 本周完成：上线客户反馈看板；完成 18 家客户访谈。
2. 关键发现：客户最常提到的三个问题是审批慢、报表难找、移动端不稳定。
3. 下周计划：发布移动端修复、试运行审批提醒、确定报表改版范围。
4. 风险：移动端修复依赖外部供应商周三交付。

受众/使用场景：部门负责人周会
期望页数：6–8 页
风格或情绪：简洁、专业、阅读效率优先
必须包含：风险页必须明确负责人和下一步
直接生成最终版
```

预期结果：AI 直接将已有信息转成有起承转合的周报，不会重复询问已经写清的完成项、计划和风险；交付前会检查页面、导航与交互。

## 3. 有品牌素材和截图

```md
请调用 `generate-html-ppt` 技能，帮我制作一份 HTML 演示文稿。

我要向客户介绍我们的新版本产品。核心信息是：新版本把审批、报表和移动端体验整合到一个工作台，客户可以更快找到数据并完成协作。

受众/使用场景：客户产品发布会，20 分钟
期望页数：10 页左右
风格或情绪：可信、有科技感，但不要炫技
品牌素材：品牌主色 #1565D8；Logo 路径 [填写路径]；产品截图路径 [填写路径]
必须包含：发布节奏、三项核心能力、客户能获得的业务价值
先给我提纲和风格建议
```

预期的第一步：AI 会优先使用提供的 Logo、品牌色和产品截图，先给发布叙事与风格方向。确认后再制作，不会把产品截图替换成虚构图片。
